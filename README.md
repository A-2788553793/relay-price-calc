# 中转站计算工具

一款 Windows 桌面小工具，用于对比多个模型在不同中转站上的价格高低。

## 功能

- 最多同时对比 4 个模型，模型名称可以自己改，比如改成“某某中转站”。
- 每个模型分别填写输入、输出、缓存写入、缓存读取（每百万 token 单价）及平均缓存率（百分比）。
- 输入时实时计算，每个模型下方显示“价格系数”；底部给出排名、标出最便宜的模型，并显示最便宜的比其他模型便宜多少百分比。
- 全部留空的模型不参与比较；部分留空的格子按 0 计算；输入无效（非数字、负数或缓存率超过 100）时标红提示。
- 每个模型都有“清除”按钮，一键清空该模型填写的参数（保留名称）。
- 输入的数值和设置自动保存，下次打开时依然在。
- 支持浅色 / 深色主题。
- 设置中可以切换主题、更换字体（微软雅黑、等线、黑体、宋体、楷体、仿宋）、调整字号，还可以一键在桌面创建“中转站计算器”快捷方式。
- 兼容全角数字与末尾的 % 号。

## 计算公式

```
未命中 = 1 − 缓存率

价格系数 = (输入 + 输出) × 未命中
         + (缓存读取 + 缓存写入) × 缓存率
```

示例：输入 3、输出 15、缓存写入 3.75、缓存读取 0.3、缓存率 80%

```
(3 + 15)×0.2 + (0.3 + 3.75)×0.8 = 3.6 + 3.24 = 6.84
```

价格系数越小越便宜。

## 下载使用

前往 Releases 页面下载 relay-price-calc.exe，无需安装，双击即可运行。

系统要求：Windows 10 及以上版本（使用系统自带的中文字体显示中文）。

配置文件保存在 `%APPDATA%\relay-price-calc\config.json`，删除该文件即可恢复默认设置。

## 从源码编译

需先安装 Rust（https://rustup.rs）。

```
cargo test             # 运行测试
cargo build --release  # 生成 target/release/relay-price-calc.exe
```
