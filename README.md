# 中转站计算工具

一款 Windows 桌面小工具，用于对比两个模型在中转站上的价格高低。

## 功能

- 分别填写模型1和模型2的输入、输出、缓存写入、缓存读取（每百万 token 单价）及平均缓存率（百分比）。
- 输入时实时计算，并在每个模型下方显示“价格系数”。
- 底部自动对比并显示“模型1更便宜”或“模型2更便宜”，同时给出便宜的百分比。
- 留空项按 0 计算；输入无效（非数字、负数或缓存率超过 100）时标红提示。
- 兼容全角数字与末尾的 % 号。

## 计算公式

```
未命中 = 1 − 缓存率

价格系数 = (输入 + 输出) × 未命中
         + (缓存读取 + 缓存写入) × 缓存率
```

示例：输入 3、输出 15、缓存写入 3.75、缓存读取 0.3、缓存率 80%

```
(3 + 15)×0.2 + (0.3 + 3.75)×0.8 = 3.6 + 3.24 = 6.84
```

价格系数越小越便宜。

## 下载使用

前往 Releases 页面下载 relay-price-calc.exe，无需安装，双击即可运行。

系统要求：Windows 10 及以上版本（使用系统自带的微软雅黑字体显示中文）。

## 从源码编译

需先安装 Rust（https://rustup.rs）。

```
cargo test             # 运行测试
cargo build --release  # 生成 target/release/relay-price-calc.exe
```
